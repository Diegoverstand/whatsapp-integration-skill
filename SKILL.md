# WhatsApp Integration

## What You Can Do
- Send text, media, and template messages via WhatsApp API
- Receive webhooks for incoming messages in real-time
- Build automated chatbots with intent detection
- Manage pre-approved message templates
- Create customer support systems

## Quick Setup
Go to [Facebook Developers Console](https://developers.facebook.com):
- Create/use an app
- Add WhatsApp Business API product
- Get: Phone Number ID, Business Account ID, Access Token
